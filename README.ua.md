### 📱 Про додаток:
Проста і популярна гра для двох гравців, яка часто використовується для швидкого прийняття рішень або просто для розваги. Мета гри - виграти якомога більше раундів, демонструючи правильні жести проти жестів супротивника. Гра триває до тих пір, поки один з гравців не виграє тричі..

### 🕹️ Фунціонал:
  - статистика гравця
  - зміна імені гравця
  - зміна аватарки гравця
  - зміна часу раунда
  - зміна фонової музики
  - ігрові правила
  - пауза у грі
  - статистика лідерів

### ⚙️ Стек:
- Swift 5.9
- UIKit
- UserDefaults
- Minimum target iOS 15.0
- MVC architecture
- SnapKit
